### Sobre mí

Estoy en 9.º semestre y me interesa la infraestructura de TI: redes, servidores y el soporte del hardware que los sostiene. También desarrollo backend con Node.js y MySQL. Hice mi servicio social en el área de cómputo del CETIS 157, donde di mantenimiento preventivo y correctivo a cerca de 40 equipos.

### Lo que hago

| Área | Experiencia |
|---|---|
| **Redes** | Subneteo, VLANs, DHCP, topologías en Cisco Packet Tracer, cableado estructurado y ponchado UTP |
| **Servidores** | Windows Server y Ubuntu Server en VirtualBox con DHCP, DNS, HTTP, SSH y FTP |
| **Hardware** | Diagnóstico, mantenimiento preventivo y correctivo, instalación de sistemas operativos y recuperación de equipos |
| **Backend** | APIs REST con Node.js y Express, y modelado de bases de datos en MySQL/MariaDB |
| **Datos** | Análisis con Pandas y visualización en Power BI |

### Proyectos

**[Tasker](https://github.com/jesusrosasav04/Tasker)**: plataforma web para contratar servicios locales con especialistas verificados. Es un proyecto en equipo de 4 personas en el que fui **líder del proyecto**: planeación de sprints, gestión de riesgos, control de cambios e integración del código con ramas por funcionalidad en Git. También codesarrollé el backend en Node.js/Express con MySQL: autenticación con JWT y control de acceso por roles, la estructura base de la API REST y el módulo de calificaciones.
